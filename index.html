Strength comparison uses the allowable bending stress you enter; no buckling, shear-strength, load-combination, or code-compliance checks are made.

This tool provides preliminary calculations for an idealized prismatic beam. It does not evaluate lateral restraint, buckling, shear strength, load combinations, connections, or code compliance. Verify inputs and design decisions with a qualified professional.
Steel section data: AISC Shapes Database v16.0. Lumber dimensions: American Wood Council. Catalog files are stored in 01_data/; lumber species/grade material values must be supplied separately.
