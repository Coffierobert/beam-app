# Project layout

This is a single-file web app. Keep `index.html` at the repository root so GitHub Pages can serve it. Keep `AGENTS.md`, `spec.md`, and `prompts.md` at the root as well.

Use the numbered folders for all other project files:

- `00_planning/` for planning notes and sketches.
- `01_data/` for data files.
- `02_validation/` for hand calculations and test cases.
- `03_output/` for screenshots and exported results.

Save every new file in the appropriate root location or numbered folder; do not add other files at the root.
